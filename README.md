# arduino-uno-ambilight-pc

## Introduction

Personal project for `Ambilight` on PC using `Arduino Uno`. It is based on the original `Adalight` sketch, but with some modifications to adapt it to the needs of a customs `Ambilight` setup, with a leds strip of `WS2812B` with 114 leds.

## Usage

The sketch `sketch_adalight_placa_original_reproducido_chatgpt.ino` is currently used in the Arduino Uno board.
